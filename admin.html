How to update your live site

  1. Add or remove videos and channels above
  2. Click "Generate portfolio.json"
  3. Click "Download File" to save the file
  4. Replace the portfolio.json in your project folder:
    C:\Users\carlo\Documents\tbarba-portfolio\portfolio.json
  5. Open a terminal in your project folder and run:
    git add portfolio.json && git commit -m "Update portfolio" && git push
  6. Wait 1-2 minutes — your live site updates automatically!

Or just tell Claude Code: "update my portfolio and push" and it'll do it for you.
